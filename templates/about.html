開発ストーリー

私自身が転職活動をしていたとき、いくつもの求人サイトを行き来するのが思った以上に大変で、少し疲れてしまうこともありました。「もし、いろんなサイトの求人をまとめて探せたら、もっと楽しく前向きにお仕事探しができるのに…」そんな気持ちが、このプロジェクトのはじまりです。
年末年始のお休みを使って、「自分の理想のジョブボードを、思いきって自分で作ってみよう」とチャレンジしてみました。
技術的なワクワクと、同じように悩んでいる方の力になれたらという想いを込めて、心を込めて開発しています。
「欲しい未来は、自分の手で」――そんな気持ちで、これからも少しずつ進化させていきます。

なぜこのプロジェクトを作ったのか

日本のテック業界で活躍したい方々に、より多くのチャンスと情報を届けたいという思いから、この求人ポータルを開発しました。大手サイトでは見つけにくい求人や、最新の働き方に関する案件もできるだけ幅広く掲載できるよう心がけています。
また、スクレイピング・データ処理・Web開発の技術力を総合的にアピールできる場としても本プロジェクトを位置付けています。

開発・仕事へのこだわり

  • データドリブン：実際の求人データを収集・分析し、ユーザーに価値ある情報を提供
  • ユーザー中心：シンプルで高速、スマホでも快適なUI/UXを追求
  • 自動化・効率化：Pythonによるスクレイピング・データ整形・API設計を徹底
  • 透明性・再現性：コード・データ処理の流れをドキュメント化し、誰でも検証可能に
  • 最新技術志向：FastAPI, MongoDB, Jinja2, Bootstrapなどモダンな技術を積極的に採用

Development Story

When I was job hunting, I found it surprisingly exhausting to jump between multiple job sites, and sometimes I felt a bit overwhelmed. I thought, "If only I could search across various sites in one place, job hunting would be more fun and positive..." That feeling was the start of this project.
During the New Year holidays, I decided to take the plunge and build my ideal job board myself.
I developed this site with excitement for technology and a desire to help others facing similar challenges.
"Create the future you want with your own hands."—With that spirit, I will keep evolving this project step by step.

Rough Development Process

  1. Clarified requirements and envisioned the ideal job board
  2. Scraped and processed job data with Python
  3. Devised robust methods for stable, large-scale data collection and error handling
  4. Saved data to MongoDB
  5. Built API and web app with FastAPI
  6. Created and designed UI with Jinja2 and Bootstrap
  7. Improved UI and mobile experience with CSS
  8. Enhanced search filter features
  9. Summarized and classified jobs using Azure Foundry LLM
  10. Deployed and operated on Azure App Service

I developed this job portal to deliver more opportunities and information to people who want to work in Japan's tech industry. I strive to include jobs that are hard to find on major sites and those reflecting the latest work styles.
